# Licensing boundaries (bpirouter-feeds)

> **Status: the licensing boundaries were finalized by legal review on 2026-08-05.**
> If this document conflicts with the root `LICENSE`, **this document takes
> precedence**. Proprietary terms in `LICENSE` apply only to material identified
> here as proprietary.

This OpenWrt package feed contains two distinct categories: package recipes,
which run inside the OpenWrt build system and control compilation and
installation, and the packaged payload, which is this project's proprietary
program. Their licences must be considered separately.

## 1. Path-level scope

| Path | Licence | Notes |
|---|---|---|
| `net/bpirouter-ui/Makefile` | **GPL-2.0** | See section 2 |
| `net/bpirouter-base/Makefile` | **GPL-2.0** | See section 2 |
| `net/bpirouter-base/files/**` | **GPL-2.0** | Banner and first-boot configuration scripts installed in the image; see section 2 |
| `net/bpirouter-ui/files/**` | **Proprietary** | Not version-controlled; generated by bpirouter-ui/deploy/build.sh: Go binary, Vue build output and deployment configuration copies; see section 3 |
| Original repository `README.md` | **Proprietary** | Not the generated build instructions in the public delivery |

## 2. Why the Makefiles and base files use GPL-2.0

Both Makefiles begin with:

```makefile
include $(TOPDIR)/rules.mk
include $(INCLUDE_DIR)/package.mk
```

They can run only inside OpenWrt's build system. They are scripts controlling
compilation and installation within the meaning of GPLv2 section 3. They must
be supplied with GPL binaries, and recipients must be free to use, modify and
redistribute them.

`net/bpirouter-base/files/` contains the banner (11 lines of ASCII art) and
`99-bpirouter-defaults` (a 76-line uci-defaults script), installed in the image
and used on first boot. They are small; GPL-2.0 removes ambiguity without a
meaningful cost, instead of turning a defensible boundary into a disputed one.

Copyright remains with the author; licensing does not transfer ownership.

## 3. Proprietary payload

`bpirouter-apid` (Go) and `www/` (Vue build output) under
`net/bpirouter-ui/files/` are proprietary and are **not** GPL corresponding
source. The classification is based on these technical facts:

```text
CGO_ENABLED=0                            No C library linking
Dependencies: jwt (MIT), osutil (MPL-2.0) No GPL-only libraries
System interaction: exec.Command        Independent processes and a CLI boundary
Commands include uci and ubus
```

They are treated as an aggregate, not a derivative work, under the GPL.

The Makefile above is the recipe that installs the payload into the image.
Different licences for the free recipe and proprietary payload are expected;
this is a common arrangement for commercial components in the OpenWrt ecosystem.

The independence classification of `bpirouter-ui` was finalized by legal review
on 2026-08-05. See the README supplied with this source.

## 4. Trademarks and branding

The BpiRouter name, logo and brand identifiers are not licensed by any software
licence. Retaining trademark rights is consistent with the GPL, but trademark
terms must not restrict modification or redistribution of GPL-covered code itself.
