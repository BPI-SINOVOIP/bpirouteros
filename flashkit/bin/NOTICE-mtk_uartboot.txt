The source accompanies the binary so that conveying the kit satisfies AGPL-3.0
section 6. The tool is a separate, independent program invoked from a shell --
BpiRouter neither links against it nor derives from it, so it is an aggregate
under section 5 and its licence does not extend to the rest of this kit.

Two things worth knowing before relying on this:

  - The v0.1.1 tag archive carries no LICENCE file (upstream added it later).
    The AGPLv3 text shipped here was taken from the repository's main branch;
    Cargo.toml at v0.1.1 does declare `license = "AGPL-3.0-only"`.
  - The source archive is upstream's own tree, which pins every dependency
    exactly via Cargo.lock but does not contain them. A build needs crates.io
    reachable. Run `cargo vendor` against this tree if a fully offline,
    dependency-complete corresponding source is ever required.

Host requirement: x86_64 Linux. The binary is static-pie linked, so it needs no
runtime libraries, but it is NOT portable to arm64 hosts -- build from the
bundled source or fetch the matching upstream asset if flashing from one.

Used by RUNBOOK-r3mini.md and RUNBOOK-openwrt-one.md to push the BL2 payload
over UART on boards that cannot be provisioned from SD (archetypes 2 and 3).
